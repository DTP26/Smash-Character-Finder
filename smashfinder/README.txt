Project Name: Super Smash Bros Ultimate Main Picker

Decription: Super Smash Bros Ultimate Main Picker uses data straight from the ultimate frame data
website to calculate which character would be best for the user based on their answers to various questions
they're prompted with. Almost every piece of information is taking straight from the website except for
the "effective range" information, which is more high/opionated, so I hard coded those myself.

The program works by first loading all of the data into fighter objects, storing those fighter objects into
a map, and then iterating through the map of fighters and weighting their scores based on the answers recieved from
the user and their stats. The user starts the program by running the Main class.

The category covered is Document Search due to, as described earlier, a majority of the information being
derived from the ultimate frame data website.

This was a solo project, and admittedly one I wish I had more time to work on before the due date. If I had more
time (I will likely work on this more in my own time), I would've used graph algorithms to form
links between characters in order to answer questions such as "What characters are most/least similar to Mario". This
unfortunately did not make it into the submission version. I also really want to add
more characteristics eventually such as character viability, the series they're from, and more.
